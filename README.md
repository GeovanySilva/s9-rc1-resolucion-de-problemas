# Inventario RC1
Proyecto Java por consola para una ferretería. Requiere JDK 17 o posterior.

En IntelliJ IDEA, abrir esta carpeta, marcar src como Sources Root si hace falta
y ejecutar el método main de interfaz.Consola.

Pruebas.txt contiene las entradas y salidas reales de cinco ejecuciones.
Los datos se conservan en memoria durante la sesión.
